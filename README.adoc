# microservice-updater-frontend

A Streamlit frontend for our https://github.com/WSE-research/microservice-updater project.

== Preparation

Install all dependencies:

```
python3 -m pip install -r requirements.txt
```

== Start applications

Use Python 3.9 as Streamlit is currently not compatible with Python 3.10+.

```
python3.9 -m streamlit run app.py --server.enableStaticServing true
```

= microservice-updater-frontend

A Streamlit frontend for our https://github.com/WSE-research/microservice-updater project.

== Preparation

Install all dependencies:

[source]
----
python3 -m pip install -r requirements.txt
----

== Start applications

Use Python 3.9 or 3.10 as Streamlit is currently not compatible with Python 3.11.

[source]
----
export BACKEND_URL=
python3.10 -m streamlit run app.py --server.enableStaticServing true
----

available at https://hub.docker.com/r/wseresearch/microservice-updater-frontend
